# 🎮 Furia ChatBot

Este projeto é uma aplicação web interativa desenvolvida para simular um chatbot temático sobre o time de CS:GO da FURIA. O objetivo é proporcionar uma experiência divertida e informativa para fãs da organização, permitindo interações com respostas automatizadas sobre jogadores, histórico, curiosidades e muito mais.

- **Frontend**: React
- **Backend**: Node.js + Express

---

## 📦 Pré-requisitos

Certifique-se de ter instalado:

- Node.js
- npm (já vem com o Node)

---

## 🔧 Backend (Node.js)

1. Vá para a pasta do backend:

```bash
cd back
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor:

```bash
npm start
```

---

## 💻 Frontend (React)

1. Vá para a pasta do frontend:

```bash
cd front
```

```bash
cd reactproject
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o frontend:

```bash
npm start
```

---

## 🚀 Funcionalidades

- ✅ ChatBot interativo sobre o time FURIA

- ✅ Respostas automáticas com base em perguntas sobre o time

- ✅ Informações sobre jogadores, histórico e curiosidades
